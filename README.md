# Mini Pokédex

A single-page Pokémon web application created using HTML, CSS, JavaScript, and two public APIs.

## Features

- Search for Pokémon by name or Pokédex number.
- View Pokémon sprites, types, abilities, and base stats.
- Display a matching Pokémon trading card.
- Discover random Pokémon from the original 151.
- Receive feedback for invalid searches.
- Responsive retro Pokédex-inspired design.

## APIs Used

**PokéAPI:** https://pokeapi.co/

Provides Pokémon names, sprites, types, abilities, and base stats.

**TCGdex:** https://tcgdex.dev/

Provides Pokémon trading card data and images.
